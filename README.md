# Autonomous Drone

AI-powered autonomous drone for search-and-rescue operations.

## Project Structure

### computer_vision/
Human detection and visual perception.

- YOLO training
- Dataset preparation
- Inference
- Survivor detection

### slam/
Localization and mapping.

### arduino/
Drone hardware and embedded software.

- ESP32 flight controller
- ESP32-CAM
- Sensor integration
- Motor/ESC control
